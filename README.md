

# EAII - Enterprise AI Incident Intelligence

## Purpose
An Agentic AI platform for enterprise incident investigation,
root-cause analysis and evidence-backed recommendations.

## Current Features
- FastAPI backend
- Health check API
- Automated API testing

## Technology
- Python
- FastAPI
- Pytest
- Git

## Run Locally
python -m uvicorn app.main:app --reload

## Run Tests
python -m pytest -v
